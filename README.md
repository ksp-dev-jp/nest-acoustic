# NEST Acoustic

長時間録音から鳥類の鳴き声候補を抽出し、山口県・季節フィルターと原音確認で判定するWebアプリ。

共有用アプリ: https://ksp-dev-jp.github.io/nest-acoustic/

## 使い方

1. 音声を選択し、録音開始日時と調査地域を確認します。
2. 「解析開始」で候補を抽出します。初回は解析モデルをダウンロードします。
3. 候補の原音を最後まで再生して、承認または却下します。
4. 「承認済み」または「全件CSV」で結果を保存します。

種名を付けられない音声区間も「鳥声候補・種未確定」で残します。「種名の状態」から絞り込み、原音を最後まで再生して「候補を承認」または「却下」を選べます。鳥の声かどうかも原音で確認してください。種未確定の候補を承認しても、鳥種は未確定のままです。種名スコア・地域スコアは空欄でCSVに出力します。鳥種照合が失敗した場合も、抽出済みの音声候補を種未確定として確認できます。

初期表示は全時間帯です。夜間のみの表示も選べます。抽出は見逃し抑制を優先します。24kHzに変換した音を約43msの窓・約21ms間隔で連続測定し、1分ごと・250Hz〜12kHzの周波数帯ごとの背景音（20パーセンタイル）に対して6dB以上強い音を確認対象にします。絶対音量−85dB未満、対象帯域の比率15%未満は除外します。1.5秒ごとにピークを選び、近すぎるピークを整理して前後3秒を残します。録音全体の160区間上限は廃止しました。夜間の候補を優先します。

候補には雑音も含まれます。小さい声や背景音に埋もれた声、長く続いて背景音とみなされた声の見逃しは残ります。候補数が増えるため、解析と原音確認には以前より時間がかかります。一覧は50件ずつ表示し、CSVには表示中のページだけでなく全件を出力します。

更新前の確認結果も元の解析条件のまま復元できます。新しい抽出を適用するには、必要に応じて従来のCSVを保存したうえで再解析してください。

確認結果は同じブラウザ内に保存します。同じ音声を選び直すと再開できます。録音のアップロードや利用者間の結果共有は行いません。ブラウザのデータを消すと保存結果も消えます。

## 精度を検証する

一覧の「確認順の参考（試験）」で、全鳥種の最大個別スコアが0.1以上の通常確認、0.1未満の低スコア候補、未計測を分けられます。最大種スコアは鳥声の確率ではなく、低スコアも雑音とは確定していません。初期表示と全件CSVには全候補を残します。過去の結果は再解析するまで未計測です。

`audit.html` は専門家の正解データ作成用です。実験結果JSONと元の録音を端末内で読み込み、候補がない時間も3秒ごとに確認できます。鳥声あり／鳥声なし／判断保留、複数鳥種・雑音メモ、JSONの保存・再開に対応。未確認や判断保留は負例にせず、全区間の確認完了までは暫定集計と表示します。データは外部に送信しません。

既存録音の探索的比較を再実行する場合は、ローカルのモデルキャッシュを用意し、次のコマンドに対象パスを渡します。現スクリプトの地域・日時は萩市・2026年3月2日05:50に固定されています。ほかの録音への転用時は地域・日時を変更してください。既存ラベルのない時間は雑音とみなしません。出力は無視対象の `outputs/` に保存してください。

```sh
node scripts/experiment-bird-detection.mjs --audio <WAV> --manual <手動記録JSON> --candidates <候補JSON> --baseline <現行検証JSON> --out outputs/<実験名>
node scripts/summarize-bird-experiments.mjs outputs/<実験名>
node scripts/package-expert-review.mjs outputs/<実験名>
```

最後のコマンドはネット接続不要で開ける単一HTMLと調査データを専門家キットにまとめます。原音は含めません。キット・回答・原音は公開リポジトリに追加しないでください。専門家へ共有するには所有者が合意した方法で別途渡してください。

## 開発・公開

Node.js 24を使用します。

```sh
npm ci
npm run test:review
npm run test:audio
npm run test:audit
npx tsc --noEmit
npm run build:pages
npm run preview:pages
```

GitHub Pages用の出力先は `dist-pages/`。`main` へのpushで `.github/workflows/pages.yml` がビルド・公開します。PagesのSourceはGitHub Actionsです。既存Sites用の `npm run build` と `npm run dev` も使用できます。

`raw/`、`outputs/`、環境変数ファイルはGitの追跡対象外です。実録音・調査成果・認証情報を追加しないでください。

## 一時公開の終了

共有が終わったらGitHubのSettings → Pagesでサイトを非公開にし、Settings → General → Danger ZoneでリポジトリをPrivateに戻します。Public期間中に取得されたソースコードのコピーは取り消せません。

## 判定モデル

音声分類: [BirdNET Live](https://github.com/birdnet-team/birdnet-live-app) のBirdNET+ v3.0-preview3.1。地域・季節: GeoModel v3.0.4。モデルはブラウザから公式配布元へアクセスして取得します。各モデルのライセンス条件は配布元を確認してください。

候補は自動同定の確定結果ではありません。オオタカの鳴き声タイプの表示は録音時期からの区分です。
