## 2. 回答から読み取れる技術要件

### 2.1 入力
- **mp3 と wav の両対応が必須。** 現行は長時間録音を PCM WAV のみ逐次読み込みで対応しており、mp3 はブラウザで一括デコードするため長時間ファイルでメモリ不足になる恐れがある。
- **Song Meter Mini Bat 2** はバット用機器のため、高サンプリングレート（例: 384 kHz 等）の WAV が来る可能性がある。鳥用マイク使用時の実際の設定値を実データで確認する。解析時は 48 kHz へのリサンプリングが前提（現行実装済み）。
- Song Meter 系はファイル名に録音日時が入る（例: `XXXX_20260401_203000.wav`）ことが多く、**録音開始時刻の自動取得**に使える。ICレコーダー2機種はファイル名規則が異なるため、実データで確認する。
- 機器によってゲイン・ノイズ特性が大きく異なるため、検出閾値を機器ごとに調整できる必要がありそう。

### 2.2 対象種・判定
- 未登録の3種（ミゾゴイ、ヒクイナ、ケリ）とオオタカを和名マッピングに追加する。
- **ケリ・オオタカは夜行性ではない。** 現行の「夜間のみ」フィルタ（18:00〜6:00固定）で除外されてしまうため、フィルタ条件を見直す。
  - 案: 「対象種のみ」フィルタを別途設ける／夜間判定を日の出・日の入り時刻ベースにする。
- オオタカは**鳴き声の種類（鳴き交わし・交尾声・餌乞い）の区別**を求められている。BirdNET は種レベルの判定のみのため、以下のいずれかが必要。
  - 録音日から時期区分を付与し、鳴き声タイプの「推定」として表示する（簡易）
  - 鳴き声タイプ別の分類器を別途用意する（要学習データ、工数大）
- 地域が西日本に限られるため、対象外地域の種を候補から除外・減点する地域フィルタを検討する。

### 2.3 精度検証
- 受領した実データで、対象8種＋オオタカの検出率・誤検出率を確認する。
- 特にミゾゴイ（低い「ボーッ」という声）、ヨタカ（連続音）はモデルが苦手な可能性があるため優先的に確認する。
